Tasks & Events

任务、事件,

Command Line

脚本里也能喊一嗓子

内置 doris 命令行,一条命令把通知推到刘海或手机,也能直接建笔记 —— CI 跑完、部署结束、长任务收尾,都能自己汇报。

zsh — doris
$ doris notify --title "构建完成" --source claudeCode
✓ 已送达 · 横幅已显示
$ doris push --to "Gavin's iPhone" --title "测试通过"
✓ 已推送到 1 台设备
$ doris note add --title "想法" --body "试试新布局"
note 已创建 · 正在同步到 iCloud
$
iCloud Sync

一个库,两端都在

Mac 与 iPhone 通过 CloudKit 共享同一个 SwiftData 库。在 Mac 上改的,手机上几秒就到 —— 数据存在你自己的 iCloud 里,不经过任何第三方服务器。
